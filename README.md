# Приложение для анализа транзакций

## Описание:

Приложение для анализа транзакций - Приложение генерирует JSON-данные для веб-страниц,  
выполняет поиск по категориям, 
выводит отчет по заданным категориям.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject4.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Приложение запускается из основного модуля main, в котором собраны все функциональности приложения.
